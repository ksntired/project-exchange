# Project Exchange — демо-лендинг диагностики системы управления

Статический шаблон лендинга для страницы услуги «Диагностика системы управления».
Проект содержит набор готовых секций (хиро-блок, этапы диагностики, результаты, кейсы,
форма контакта, футер) и небольшие UI-улучшения: экран загрузки, кастомный курсор,
аккордеон для шагов и карусель кейсов. Файлы просты для кастомизации и развёртывания
как статического сайта.

---

## Краткое содержание

- Язык: HTML/CSS/JavaScript (Vanilla)
- Фреймворк: Bootstrap 5 (CDN)
- Папка проекта: корень репозитория содержит `index.html`, статические ассеты в `assets/`.

## Скриншот / Превью

> Откройте `index.html` в браузере для локального просмотра.

---

## Функции

- Блок «первый этап…» с визуальной карточной сеткой
- Аккордеон "Как проходит диагностика" — каждый шаг разворачивается отдельно
- Блок «Какой результат вы получите» с карточками
- CTA-блок и форма консультации (визуально — без серверной логики)
- Карусель клиентов (Bootstrap Carousel)
- Экран загрузки: матовое стекло с переливающимся градиентом (показывается 3 секунды)
- Блокировка прокрутки пока виден лоадер
- Кастомный следящий курсор (лазурный кружок) для десктопа

## Как запустить локально

Проект статический — достаточно открыть `index.html` в браузере. Для корректной
работы некоторых браузеров (CORS, загрузка локальных ресурсов) рекомендуется
запустить простой HTTP-сервер.

Примеры:

```bash
# Python 3 (порт 8000)
python -m http.server 8000

# или, если установлен node.js, можно использовать http-server
# npm i -g http-server
# http-server -c-1
```

После запуска откройте http://localhost:8000 в браузере.
